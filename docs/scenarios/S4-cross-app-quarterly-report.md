## 1. 一句话场景

**工业软件公司「云巡科技」的运营专员**，每季度末要向管理层交一份《季度经营分析报告》：
数据来自订单系统导出的《2026年Q3运营数据.xlsx》，报告用公司下发的 Word 模板写，最后导 PDF 发管理层群。
现在她得手工清洗明细（渠道名空格/大小写、文本金额、取消单）、做透视汇总、**把数字一个个抄进 Word 表格**、
**截 Excel 的图贴进文档**、把模板里上季度（Q2）的月份和数字全换掉、更新目录页码，最后导 PDF；
**约 60 分钟，每季度一次，而且最容易出的事故就是"报告里的数字和 Excel 对不上"**（抄错、抄漏、用了旧数）。

## 4. 现在手工怎么做（痛点）

1. Excel 里复制一份，手工清渠道列空格、把文本金额一列列改成数值；
2. 筛选掉"已取消"和测试单，删表尾垃圾行；
3. 做透视表：渠道 × 销售额 / 订单数，再手工算客单价和占比；
4. 另存一份留档；
5. 插柱形图和折线图，**右键另存为图片**（或截图），存到 `artifacts\`；
6. Word 打开上季度报告 → 另存为本季度 → 逐个把 Q2 的月份、数字、"第二季度"改掉（**这一步最容易漏**）；
7. 把 Excel 透视出来的数字**一个个手抄**进 Word 表格；
8. 把两张图插进去、拖到不超版心；
9. 更新目录、改页脚页码、导 PDF、发群。

**耗时约 60 分钟；每季度一次；最典型的返工是"管理层发现报告里的数跟系统里的对不上"——抄错、抄漏、或者用了上一季度的数。**

## 6. 期望覆盖的能力

- **Excel**：`open_workbook` → `read_range` → `write_range` → `set_formula`/写值 → `set_number_format` → `set_cell_format` →
  `find_replace`（渠道名归一）→ `create_sheet` → `create_chart` → `export_chart_as_image` → `save_as` → `close_workbook`
- **Word**：`create_document` 之外的**基于模板另存**路径 → `get_document_text`/`get_paragraphs` 定位 →
  `find_replace`/`replace_range`（清 Q2 残留）→ `get_tables` + `set_table_cell`（换数字）→ `insert_table`（新增 2×3 表）→
  `set_table_format` → `insert_image` → `generate_toc` → `insert_page_numbers` → `insert_header` → `save_as`
- **跨应用**：`wps_batch`（连续调用）、`wps_call`（非广告工具）、`wps_common_save_as`、`wps_convert_to_pdf`、
  `wps_status`、`wps_excel_get_open_workbooks` / `wps_word_get_open_documents`（收尾核对）
- **导航/目标定位**：`switch_workbook` / `switch_sheet` / `switch_document`（两应用同时开着时的目标歧义）

## 7. 验证器陷阱（预告，写验证器时就要堵住）

> S1 抓出 7 处、S2 抓出 7 处、S3 抓出 2 处验证器自身缺陷，其中 S3 有一次**对模型的假指控**。
> 本场景的 9 条陷阱在写核验器时先堵住，并如实标注哪些是实测确认、哪些是预判。

| # | 陷阱 | 对策 |
| --- | --- | --- |
| 1 | 文本金额读回来可能是 `str`，也可能是"数值 + 文本格式"（numFmt `@`） | 两种都认；先做"能否转成 float"的判定，再看 `number_format` |
| 2 | 渠道归一不能只做 strip+casefold（`Douyin`→`抖音` 是映射，不是大小写） | 按 `expected.json` 的**映射表**比对，映射表外的一律判红 |
| 3 | Q2 残留判定要归一化全半角/空格；且**排除合法的历史对照语境** | 本场景模板**不放**任何"上季度对照"合法语境，判据才立得住（0 次） |
| 4 | 万元换算舍入：`round(x,1)` 与 Excel 显示可能差 0.05 | 容差 ±0.05 万元，否则假指控 |
| 5 | TOC 三形态：`w:fldSimple` / `w:instrText` / SDT | 三种都认（复用 S2 陷阱 5） |
| 6 | 页脚 `PAGE` 域可能在多个 footer part、也可能包在 `fldSimple` 里 | 遍历全部 footer part + 两种域形态 |
| 7 | 模板自带装饰图会干扰"两张图已插入" | **按 sha256** 与 `media` 里内容配对，只认与 `artifacts\*.png` 一致的图片 |
| 8 | 新旧表格都叫"渠道表"：`get_tables` 顺序可能与文档顺序不同 | 按表头文本（渠道 / 销售额 / 订单数 / 占比）定位，不按索引 |
| 9 | PDF：只判存在 + `%PDF-` + 页数 | 不判与 docx 视觉一致；不判 PDF 里的数字（XML 才是真值来源） |

## 8. 已知不可判项

- 「手工 60 分钟」是场景设定，不是断言。
- 版式好不好看、图是否美观、配色是否协调：不判。
- 「图没撑出版心」只做**可算的那一半**（图片 EMU 宽 ≤ 版心宽）；视觉溢出、遮挡：人工看，不进硬判据。
- PDF 与 docx 是否视觉一致：不判。
- 客单价两位小数的取整方式（四舍五入 vs 截断）：容差 ±0.01，不判方法。
- 目录"好不好看"、页码在 WPS 界面里是否真的渲染：不判（只判文件里有没有）。
