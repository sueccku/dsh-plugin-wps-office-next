## 4. P0 缺陷：小数参数写不进 PPT 几何属性（已修）

### 4.1 症状与独立复现（**不经模型**，直接对本仓库 MCP server 发 `tools/call`）

`tools/repro-set-shape-position.mjs`：

| 用例 | 参数 | 结果 |
| --- | --- | --- |

| C | `left:100.5, top:120.25` | ❌ `指定的转换无效`（动作：setShapePosition） |
| I | `left:100, top:100.5` | ❌ |
| J | `left:100.5, top:100` | ❌ |
| K | `left:100.0, top:100.0`（整数值的小数） | ✅ |
| L | 整数坐标 + `width:400.5` | ❌ |
| N | `left:54, top:167.75`（**正是 `get_shapes` 回读出来的坐标**） | ❌ |

| 对照 | `align_shapes` / `add_textbox` / `set_slide_size`（都走 `Set-ComValue` 或 `[double]`） | ✅ |

### 4.2 根因（带行号的堆栈，PS 5.1 `-STA` 点源桥脚本复现）

`tools/probe-action-ps51.ps1` 按宿主的调用方式（`$req.params | ConvertTo-Json -Compress` → 动作内 `ConvertFrom-Json`）复现：

```
=== req id=1 types: left=Int32 top=Int32
    result: （成功）
=== req id=2 types: left=Decimal top=Int32
    EXCEPTION System.InvalidCastException: Specified cast is not valid.
    at  D:\dsh\a\host\wps-actions.ps1:6759  if ($null -ne $p.left) { $shape.Left = $p.left }
=== req id=3 types: left=Int32 top=Decimal
    EXCEPTION System.InvalidCastException ...
    at  D:\dsh\a\host\wps-actions.ps1:6760  if ($null -ne $p.top) { $shape.Top = $p.top }
```

- **PS 5.1 的 `ConvertTo-Json` → `ConvertFrom-Json` 往返把带小数的数字解析成 `System.Decimal`**（整数是 `Int32`）；
- `Decimal` 直接赋给 COM 的 Single 属性（`Shape.Left` 等）→ `InvalidCastException`；
- 同一份代码里 `Set-ComValue` 的注释（`wps-com.ps1` §"COM boundary helpers"）**早就写明**"每个被写的 COM 成员都必须走这两个助手"，
  `setShapePosition` 等 5 处是漏网存量。
- 补充：直立裸 COM 探针（pwsh 7 / PS 5.1、`[double]` 字面量）都**不会**触发 —— 触发条件是**"Decimal 经宿主往返到达"**，
  所以这个缺陷在单测里看不出来，必须走 `mcp/dist/index.js` 或宿主。

### 4.3 修复

`mcp/scripts/wps-com.ps1`（→ `scripts/build-host-actions.ps1` 重新生成 `host/wps-actions.ps1`，生成物幂等）：

| 动作 | 修复前 | 修复后 |
| --- | --- | --- |
| `setShapePosition` | `$shape.Left = $p.left` ×4 | `Set-ComValue $shape 'Left' $p.left` ×4 |
| `setPptTableFormat` | `$shape.Left = $p.left; $applied += "left"` ×4 | 同上 + `$applied` |
| `setImageStyle` | `$shape.Left/Top/Width/Height/Rotation = $p.*` ×5 | 全走 `Set-ComValue` |
| `insertImage`(Word) | `$shape.Width/Height/ScaleWidth/ScaleHeight = $p.*` ×4 | 全走 `Set-ComValue` |
| `replacePptImage` | `$pic.Rotation = $rot` ×1 | `Set-ComValue $pic 'Rotation' $rot` |
